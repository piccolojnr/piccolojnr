## Selected work

### [ATE05 — Restaurant POS](https://github.com/piccolojnr/ate05)

An offline-first desktop point-of-sale application built with **React, TypeScript, Tauri and SQLite**.

- Order, checkout and kitchen workflows.
- Local persistence and encrypted backups.
- Network thermal printing and installed Windows printer queues.
- Persisted receipts remain available for retry when printing fails.

[Explore the code](https://github.com/piccolojnr/ate05) · [Printer setup guide](https://github.com/piccolojnr/ate05/blob/main/docs/printer-configuration.md)

### SRC Permit System — University payments & verification

Built a self-service platform for student registration, fee payments, permit issuance and exam hall verification.

- Documented results: **1,687 students** and **GHS 165,100** processed across two semesters.
- Role-based access for students, staff and verifiers.
- Migrated a live payment integration from Paystack to ExpressPay.

**Stack:** Next.js, Prisma, MySQL, payment APIs.

[Case study](./02_projects/src-permit-system/overview.md)

A working self-service laundry locker prototype, connecting a **16-locker cabinet** to customer and staff applications.

[Case study](./02_projects/laundry-kiosk/overview.md)
